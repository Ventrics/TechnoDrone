# TechnoDrone Portfolio Assets

This file tracks the public-facing media still needed for the portfolio version of TechnoDrone.

## Upload These Later

| Needed asset | Suggested path | Notes |
|---|---|---|
| Primary logo / wordmark | `assets/brand/technodrone-logo.svg` | Source-quality logo if possible. |
| PNG logo export | `assets/brand/technodrone-logo.png` | Transparent background, useful for README and portfolio cards. |
| Small icon | `assets/brand/technodrone-icon.png` | Square crop for thumbnails or favicon work. |
| Title screen screenshot | `assets/screens/title.png` | Capture the title wordmark cleanly. |
| Gameplay screenshot | `assets/screens/gameplay.png` | Show the HUD, player, enemies, and readable action. |
| Flow State screenshot | `assets/screens/flow-state.png` | Capture the strongest powered-up visual state. |
| Game over screenshot | `assets/screens/game-over.png` | Good for score/UI polish. |
| Short gameplay clip | `assets/media/gameplay-clip.mp4` | 10-20 seconds is enough for portfolio use. |
| Social/portfolio thumbnail | `assets/media/thumbnail.png` | Bold, readable card image for the portfolio homepage. |

## Capture Guidance

- Favor sharp, readable moments over maximum chaos.
- Include one calm title or menu shot and one high-action gameplay shot.
- Make sure the HUD is legible in at least one screenshot.
- Avoid placeholder art in the final portfolio page.
- Keep file names lowercase and stable so links do not break later.
- Treat `assets/brand`, `assets/media`, and `assets/screens` as the final export locations.
