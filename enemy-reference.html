Live in-game render on the left of each card, pure silhouette on the right. Use the silhouettes as the redesign target — that's the polygon shape we trace. Source of truth for shape geometry: js/enemies.js (helpers makeRegularPolygon, makeArrowheadShape, makeJackpotShape, makeBasicShardVisuals) and js/enemy-turrets.js. Render code is mirrored from the same file's shards.draw() block so the in-game look is preserved.
